# HIM-Theory —— 「猫智能论 / 内稳态内在动机」理论的可跑实验代码

本仓库把三份同作者（王程远）文档里的理论落成**可直接复算的实验**：

| 文档 | 角色 | 本仓库中的对应物 |
|---|---|---|
| 《反思智能：存在自主动机的最简机器模型设计》（2018, A 版） | 理论母本，17 个性质体的离散状态机 | `him_core/state_machine.py`（`ci2018` 智能体） |
| 《Homeostatic Intrinsic Motivation (HIM)：基于内稳态内驱力的自主智能体架构》（C 版） | 把 A 版连续化：`L_t` / `ΔL_t` | `him_core/homeostasis.py` |
| 《【3版】基于内稳态内驱力的自主智能体架构》 | 补上三条公式与"三座桥梁" | `him_core/homeostasis.py` + `docs/results_report.md` |

**核心结论先说**：论文的伪代码 `drive = ΔL_t + hope_drive` 在数学上实现不了论文
自己声称的探索行为。直接照抄，覆盖率是 **0.45%**（智能体爬上第一个兴趣点就不动了，
12000 步里总共只位移 93 步），而不是论文写的 88.2%。补上一个论文缺失的算子
（区域新奇度的可计算形式）之后，覆盖率升到 **99.91%**、陷入率 **0%**、
兴趣区覆盖率 **99.99%**。完整论证见 [`docs/results_report.md`](docs/results_report.md)。


## 环境设置（全部对齐论文 §3.1）

| 项 | 值 | 出处 |
|---|---|---|
| 网格 | 100×100 离散 | 论文 §3.1 明写 |
| 外部奖励 | **无** | 论文 §3.1 明写 |
| 预设目标 | **无** | 论文 §3.1 明写 |
| 布局 | 随机生成 | 论文 §3.1 明写 |
| 舒适度场 φ | 20 个随机高斯兴趣点叠加，φ ∈ [0.02, 0.9] | 【3版】§4.1 补充"随机分布高舒适度区域" |
| 观测噪声 | σ = 0.05（智能体不可见，前瞻不加噪） | 论文未给，本仓库显式登记 |

φ 用 `np.maximum` 而非求和叠加：求和在兴趣点密集处会触顶并 clip 出一大片
φ ≡ 1.0 的平台，梯度消失、ΔL ≡ 0，智能体会在平台上原地随机游走 —— 这是
第一版实现里覆盖率只有 1.3% 的直接原因。

## 指标口径

论文 §3.1 / §4 用了四个指标却**一个都没给计算口径**。本仓库把口径显式写死在
`experiments/metrics.py`，并在报告里标注了每一处与论文文字可能不符的地方：

| 指标 | 本仓库口径 |
|---|---|
| 环境覆盖率 | 被访问过的格子数 / 100² |
| 收敛步数 | 覆盖率增长首次连续 500 步新增 < 10 格时的步数 |
| 陷入局部极小值 | 已收敛 **且** 收敛时覆盖率 < 50% |
| 能耗 | 同时报三条：总步数 / 实际位移步数 / 单位覆盖能耗（步数÷已覆盖格数） |
| 兴趣区覆盖率 | 已访问的兴趣区格子 / 全部兴趣区格子（A 版"智能测试方法"的可量化代理） |

## 区域新奇度：本仓库补入的那个算子

论文把"区域新奇度 / 好奇心"当作核心公理（C 版 §6.3），并在 3 版 §5.2 主张
"ΔL ≈ 0 会产生内在压力去主动尝试新行为"，但**从未给出任何可计算形式**，
公式 `drive = ΔL + hope_drive` 在 ΔL = 0 处恒为 0，`argmax` 永远选"原地不动"。

本仓库实现并对照了两种形式：

```
block（论文「最近访问时刻」直译）
    novelty(j) = clip((now − last_visit(block(j))) / horizon, 0, 1)     →  0.17%

field（本仓库补入，默认）
    novelty(j) = cw · [ NB·D·(1 − V[j])  +  (D − d(j)) ]
        V[j]  是否访问过；d(j) 到最近未访问格子的曼哈顿距离（上限 D = 96）
                                                                       →  99.91%
```

`field` 的两项各自承担一个不可替代的角色：

* `NB·D·(1 − V[j])` —— **目标信号**。未访问格恒优于已访问格，因此
  `stay` 永远被否决，智能体无法停滞（这就是 3 版 §5.2 想要但没写出来的
  "停滞压力"）。
* `D − d(j)` —— **导航信号**。逐格精确的曼哈顿距离势场，**每走一步涨 `cw`**，
  梯度是常数、比 ΔL 大一个数量级；它只在未访问格取极大，因此**不会在已探索
  区域内部造出假顶点**。有了它，智能体即使把自己围死也能自己走回前沿。

两者的必要性都有消融数据支撑（`curve` / `ablation` 图与 `docs/results_report.md` §3）。

## 复现须知

* `random` / `rl` 的对照意义是**量纲参考**：它们告诉我们"在 100×100 里随机走
  12000 步大概能覆盖多少"，用来判断某个覆盖率数字是不是其实什么都没做。
* 所有随机性都由 `seed` 派生（环境种子 `1000+i`，智能体种子 `s*31+7`，
  起点种子 `s*17+3`），换机器结果完全一致。
* 论文没有公布实验代码、随机种子、超参、指标口径，因此**本仓库是"依据论文
  文本的最忠实重建"，而不是原论文实验的复现**。所有无法从文本推出的量都在
  `docs/results_report.md` 里逐条登记。
