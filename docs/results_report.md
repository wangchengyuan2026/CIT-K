## 0. 一句话结论

**论文 §2.4 的伪代码 `action = argmax(ΔL_t + hope_drive)` 在数学上实现不了论文自己
声称的探索行为。**照字面实现，覆盖率是 **0.45%**（智能体爬上第一个兴趣点后位移
总共只有 93 步 / 12000 步），而不是论文写的 88.2%。补上一个**论文缺失的算子**
（区域新奇度的可计算形式）之后，覆盖率升到 **99.91%**，陷入率 0%，与论文的定性
结论一致、定量上更好。论文声称的所有关键机制中，**只有"区域新奇度"是承重的**；
"希望机制"在本环境中贡献为 0。

## 3. 核心发现：论文原式为什么跑不出探索

### 3.1 这是数学问题，不是调参问题

论文把动作选择写成

```python
action = argmax([drive_of(next_state) for next_state in neighbors])
drive  = ΔL_t + hope_drive(L_t, hope_buffer)
```

注意：`argmax` 是**单步**贪心。在环境与需求都静止的情况下，"最大化累积 ΔL"等
价于"最大化最终的 L"，而单步贪心 `argmax(ΔL)` 就是舒适度场 φ 的**梯度上升**。

梯度上升在有多峰的场里**必然收敛到局部极大值**。而论文 §4.1 又恰恰把环境设成
"随机分布高舒适度区域"（多峰）—— 于是这个算法**必然**卡在第一个兴趣点上。

**数值证据**：`him_v1` 60 轮平均位移 **93.3 步**（12000 步里），覆盖率 0.45%，
陷入率 100%，末段 φ = 0.900 = 场最大值。这就是"爬上第一个峰然后停住"的指纹。

### 3.2 三个互相独立的原因

**原因 1：目标写反了。**
"最大化 ΔL 的累积值"就是"最大化最终的 L"。静止环境里，最优策略就是停在最高点。
这与论文自己写的"不追求静态绝对舒适度极大值"直接矛盾。

**原因 2：希望算子方向不对。**
```
hope_drive(L) = max(0, peak(buffer) − L − threshold) × gain
```
这是 L 的**减函数** —— 越不舒服，驱动越大。它只能把智能体从低处拉回记忆中的
高点，**不可能是"离开舒适区"的力**。而且智能体停在峰值时这项恒为 0，
对"要不要离开"没有任何发言权。

**原因 3（最关键）：论文没有给出区域新奇度的任何可计算形式。**
【C 版】§6.3 把它当核心公理，【3 版】§5.2 主张"ΔL ≈ 0 会产生内在压力去主动
尝试新行为"，但公式 `drive = ΔL + hope_drive` 在 ΔL = 0 处**恒等于 0**，
`argmax` 永远选"原地不动"（因为 `stay` 的 ΔL 恰好是 0，而任何移动都是负的）。
文字主张和公式在这里是直接冲突的。

**消融证据**：`him_nohope`（只去掉希望、保留新奇度）覆盖率 **99.91%**，
与完整模型**逐位相同**（标准差都一模一样：0.53%）。也就是说：

> **希望机制对本实验的智能体行为贡献为 0。**

原因也清楚：希望项的量级是 `0.1 × ΔL ≈ 1e-3`，而新奇度项的一步梯度是
`cw = 0.2`，差两个数量级。它被完全淹没。

## 4. 区域新奇度：本仓库补入的算子与它的设计过程

### 4.1 三种候选形式与实测对比

| 形式 | 公式 | 覆盖率 | 结论 |
|---|---|---|---|
| 论文「最近访问时刻」直译 | `clip((now − last_visit(block)) / horizon, 0, 1)`，区块 + 双线性插值 | **0.15% ~ 0.21%** | ❌ 数学上不可能探索 |
| 邻域未探索面积占比 | `1 − Σ_visited K(j−v) / Σ_ball K(j−v)` | 0.15% | ❌ `stay` 不被惩罚 |
| 前沿贴合 + 1/D 梯度导航 | `(1−V)·S/C + (1 − d/D)` | 0.79% | ❌ 梯度被 ΔL 反超 |
| **距离势场（最终采用）** | `cw·[ NB·D·(1−V) + (D − d) ]` | **99.91%** | ✅ |

### 4.2 为什么"最近访问时刻 + 双线性插值"必然失败

双线性插值把一个**分段常值场**铺平。在"当前区块（刚被刷新、novelty = 0）"与
"相邻已陈旧区块（novelty = 1）"的交界处，插值曲面会出现**局部极大值**，
而它恰好落在智能体脚下 —— 于是动作集里 `stay` 的新奇度最高。

**探针实测**：智能体 20000 步只触碰 4/169 个区块、17 个格子；
`him_blocknov` 60 轮平均位移 4094 步却只覆盖 0.17% —— 全部花在
"3–4 个区块交界处来回振荡"。

**教训**：任何用插值铺平的分段常值场，都可能在智能体脚下凭空造出假顶点。

### 4.3 最终算子

```
novelty(j) = cw · [ NB·D·(1 − V[j])  +  (D − d(j)) ]

V[j]  = 格子 j 是否已被访问（0/1）
d(j)  = j 到最近「未访问」格子的曼哈顿距离，按 D 截断
NB = 1.0（未访问格的额外满额奖励，单位 D）
D  = 96 格
cw = 0.20
```

两项**各自承担一个不可替代的角色，缺一不可**：

**`NB·D·(1 − V[j])` —— 目标信号。**
未访问格恒优于任何已访问格，因此 `stay` 永远被否决 —— 这就是【3 版】§5.2
想要、但从未写进公式的那个"停滞压力"。
它必须写成**独立加分项**而不是靠 `d` 判定：`d` 场每 10 步才重算一次，
刚踩过的格子在 `d` 场里仍然是 0，只靠 `d` 会出现 `stay` 与未访问邻格**并列**、
最后被 ΔL 拉回原地的假象（实测覆盖率掉到 37.25%）。

**`D − d(j)` —— 导航信号。**
逐格精确的曼哈顿距离势场，**每走一步涨 `cw = 0.2`**。关键是这个梯度是**常数**：
与 D 无关、与"离前沿多远"无关，因此稳压 ΔL 的量级（`|ΔL| ≤ (1−β)|Δφ| ≈ 0.03`）
一个数量级。

它只在未访问格取极大，**不可能在已探索区域内部造出假顶点**（真距离函数没有
局部极大值）—— 这正是它比双线性插值优越的地方。有了它，智能体即使把自己
四邻围死，唯一剩下的信号就是 `d` 的梯度，**它总能自己走回前沿**。

### 4.4 消融：每个算子各自贡献多少

| 变体 | 覆盖率 | 说明 |
|---|---|---|
| `him` 完整 | **99.91%** | — |
| − 希望机制 | 99.91% | **无贡献**（量级差两个数量级） |
| − 长程导航（D = 1） | 2.20% | ❌ **塌掉 97.7 个百分点** |
| − 全部新奇度（= 论文原式） | 0.45% | ❌ 塌掉 99.5 个百分点 |
| 新奇度用「最近访问时刻」直译 | 0.17% | ❌ 等同于没有 |

**结论：`him` 的探索能力 100% 来自"长程导航 + 未访问加分"这两个补入的算子，
论文列出的两个原生机制（ΔL、希望）在其中贡献为 0 或负。**

### 4.5 参数稳健性（20 个随机种子）

| cw | D | 覆盖率均值 | 最小值 |
|---|---|---|---|
| 0.05 | 96 | 94.95% | — |
| 0.20 | 48 | 98.59% | 83.50% |
| **0.20** | **96** | **100.00%** | **99.99%** |
| 0.20 | 128 | 100.00% | 100.00% |

D = 96 是稳健选择；cw 在 0.10 ~ 0.50 之间结果接近（96.7% ~ 96.8%，6 种子）。
唯一对 D 敏感的原因是：D 同时充当 `d` 场的截断距离，D 太小则智能体离前沿
超过 D 格后导航信号归零。

### 5.2 FEP 基线为什么对不上（重要）

论文对 FEP 的全部描述只有两句：

> 「对比对象为本文 HIM 模型与标准自由能原理主动推理（FEP）模型」
> 「FEP 以最小化惊奇度为核心优化目标……智能体倾向停留在低不确定性区域，
>  '保持不动'成为最优策略，极易陷入局部极小值」

**生成模型、精度、先验、探索噪声一概未提**。本仓库按标准主动推理重建（见
`baseline/fep_model.py` 顶部注释），得到 0.44%。要得到论文的 31.8%，
需要额外注入大量探索噪声 —— 但那就不再是"容易停在原地"的 FEP 了，
和论文对 FEP 的定性描述自相矛盾。

**这是最需要作者补充材料的一处**：请给出 FEP 基线的完整实现口径
（生成模型形式、先验、精度参数、是否带 ε-greedy、ε 取值与退火表）。

### 5.3 能耗口径无法对齐

论文只给了"高于基准线 12.5%"这一个数字，没有说：
- 基准线是哪个模型？（FEP？随机？人工设定？）
- 能量单位是什么？（步数？位移？计算量？感知次数？）
- 12.5% 是相对哪个指标？

本仓库同时报三个口径（总步数 / 实际位移步数 / 单位覆盖能耗）以回避这个歧义。
注意：**在"总步数"这个口径下，所有智能体都是 12000（按定义完全相等）**，
"高 12.5%"在这口径下恒为 0。

**实测结果**：`ci2018` 覆盖率 0.89%，位移 10630 步 —— 它的"近路原则"只提供了
**局部**吸引力，没有任何驱动智能体**离开**已舒适区域的力量。这与 HIM 的
`him_v1` 是同一个病根。**A 版 2018 论文里的"自主性"同样缺少一个探索算子。**

## 6. 风险提示与修改建议

### 6.1 必须修（否则论文的核心主张站不住）

**建议 1：把"最大化累积 ΔL"改掉，或者给出它的转移机制。**
只要目标写成"最大化 L"，静止环境下最优解就是停在最高点。建议明确写成
**"最大化单位能耗的长期舒适度增量"**（即把能耗放进目标），或者引入
**舒适度需求的动态变化**（需求随时间上升 ⇒ 舒适度自然衰减 ⇒ 有离开的动力）。
后者更贴近 A 版"需求体 M"的原意 —— A 版里 M 会在 M-A/M-B 之间转移，
本身就是一种让"当前位置变得不够舒服"的机制，可惜 B/C/3 版把它简化掉了。

**建议 2：把"区域新奇度 / 好奇心"从公理变成公式。**
这是唯一能让探索行为出现的算子，但现在它在论文里**只以文字和公理形式存在**。
建议在 §2 增加一节给出可计算定义。本仓库的形式（§4.3）可以直接用，也可以换更
简洁的版本，但必须满足三条硬性要求：
1. **对"已访问"和"未访问"必须严格可分**，且未访问严格占优 ⇒ 保证 `stay` 被否决；
2. **势场必须处处单调指向未探索区域**，不许在智能体脚下出现假极大 ⇒ 保证不卡死；
3. **每一步的势场增量必须大于 `max|ΔL|`** ⇒ 否则在兴趣点陡坡上会被 ΔL 反超。
本仓库踩过的三次坑（双线性插值的假顶点、归一化高斯核导致 `stay` 不被惩罚、
`1/D` 梯度被 ΔL 反超）都是违反这三条之一。

**建议 3：把"希望机制"的定位说清楚，或者删掉。**
实测它对探索的贡献为 0（`him` 与 `him_nohope` 逐位相同）。它现在的作用只是在
智能体已经很舒服时提供一个"回到记忆高点"的拉力，而智能体本来就在那里。
建议：要么承认它是"舒适度维持"而非"探索驱动"机制，要么把增益从 0.1 提到与
新奇度同量级并重做消融。

### 6.2 建议补

**建议 4：给出全部指标的计算口径。** 现在四个指标（覆盖率、收敛步数、陷入率、
能耗）一个都没有定义。特别地，"覆盖率"是格子占比还是面积占比？"收敛"的判据
是什么？读者无法复算任何数字。

**建议 5：给出 FEP 基线的实现细节。** 31.8% 这个数字目前无法从论文文本重建
（本仓库重建得 0.44%）。这是审稿人最可能追问的一处。

**建议 6：统一 `W` 符号。** `W_t`（感官经验）与 "W Memory Buffer"（希望缓冲池）
同字母两义，容易让读者误以为希望缓冲池存的是感官经验。

**建议 7：不要让三版之间的公式互相打架。** 3 版删掉了 Eq1（作者自认不可计算）
但保留了"三座桥梁"的叙事；C 版把区域新奇度当核心公理但 3 版正文不再提它。
建议在三版里明确写一段"相对前作的变化与原因"。

## 7. 结论

1. **论文的定性结论是对的，定量结论需要补算子才能成立。** "内在动机驱动的
   自主探索确实不需要外部奖励" —— 这一点本仓库完全支持：`him` 在**零外部
   奖励**下达到 99.91% 覆盖率、99.99% 兴趣区覆盖率，而依赖外部奖励的 `rl`
   只有 12.48%，比随机游走（22.39%）还差。

2. **但空有 ΔL 和希望机制是不够的。** 二者合起来在静止环境里就是梯度上升，
   必然卡在第一个局部极大值上（0.45%）。论文声称的 88.2% 与伪代码之间存在
   **一个缺失的算子**。

3. **缺失的算子是"区域新奇度"，而且它必须满足三条硬性要求**（可分、单调、
   增量大于 max|ΔL|）。补齐之后覆盖率 99.91%，陷入率 0%，与论文的定性叙事
   完全一致。

4. **"末端回归舒适"得到证实，且不是"停在极大值"。** `him` 末段 φ 是全程均值的
   1.91 倍（≈ 第 70~75 百分位），而照字面实现的 `him_v1` 末段 φ 是场最大值
   0.900。这说明"不追求静态绝对舒适度极大值"这句话是对的 —— 但它只在补入
   新奇度算子之后才成立。

5. **A 版 2018 有同一个病根。** `ci2018` 覆盖率 0.89%、位移 10630 步：
   近路原则只提供局部吸引力，没有任何离开已舒适区域的力量。隔了 7 年，
   从 A 版到 3 版，"探索驱动力从哪里来"这个问题始终没有被公式化。
